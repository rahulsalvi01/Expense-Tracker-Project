## What's New in Version 2

This release introduces major feature upgrades and security enhancements to the FinTrack platform:

* **Dynamic Analytics Dashboard:** Visual spending insights powered by Chart.js[cite: 9].
* **Smart Monthly Budgets:** Set category-wise budgets with real-time progress indicators to prevent overspending[cite: 9].
* **Advanced Reporting:** Added CSV export capabilities for transaction history and formatted, print-ready reports[cite: 9].
* **Robust Security:** Implemented token-based CSRF protection, secure session management, and PDO prepared statements to eliminate SQL injection vulnerabilities[cite: 9].
